# Круг Года

Полноценный браузерный финансовый life-sim: доска 12×7, карьера, активы, рынок, привычки, семья, банкротство, 1–4 игрока, победа по 4 условиям до 65 лет.

## Запуск

```bash
npm install
npm run dev
```

## Сборка / деплой

```bash
npm run build
```

Папка `dist` — на Vercel, Netlify или Render Static Site.

## Победа

1. Исполнить мечту  
2. Денежный поток > 0  
3. Накопить **2 500 000 ₽**  
4. Иметь ≥ **160** свободных часов в месяц  

## Новое

- ИИ-боты (до 3) с автоходами  
- Баланс под веб-партию  
- Больше событий, прогресс-бары победы, тосты, автосохранение  

Оригинальный контент и код. Билд Timeflow не используется.
